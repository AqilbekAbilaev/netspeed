# netspeed

[![test](https://github.com/AqilbekAbilaev/netspeed/actions/workflows/test.yml/badge.svg)](https://github.com/AqilbekAbilaev/netspeed/actions/workflows/test.yml)

Консольный скрипт, который замеряет скорость скачивания. Он делает несколько
запросов к указанному адресу строго по очереди, каждый раз дожидается полного
ответа и печатает статистику по времени запросов, общий объём данных и скорость.

## Требования

Python 3.10 или новее. Внешних зависимостей нет, нужна только стандартная библиотека.

## Запуск

```bash
python3 netspeed.py https://proof.ovh.net/files/10Mb.dat
```

Во время работы в stderr печатается прогресс: живой счётчик мегабайт
(только в терминале) и строка по каждому завершённому запросу. Итог
печатается в stdout:

```
Request 1/10: 887.7 ms (latency 333.4 ms), 1.05 MB
...
Request 10/10: 910.8 ms (latency 348.8 ms), 1.05 MB
Requests: 10
Request time: average 912.1 ms, median 910.8 ms, min 887.7 ms, max 938.0 ms
Latency (time to first byte): average 338.5 ms
Total downloaded: 10.49 MB
Download speed: 9.20 Mbit/s
Download speed without latency: 14.62 Mbit/s
```

Параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — | адрес, к которому стучаться (например, тяжёлая картинка) |
| `-n`, `--count` | `10` | количество последовательных запросов |
| `-w`, `--warmup` | `0` | прогревочные запросы перед замером, в статистику не входят |
| `-t`, `--timeout` | `30` | таймаут одного запроса в секундах |
| `--json` | выключен | печатать итог в формате JSON |

Если адрес недоступен, скрипт печатает ошибку в stderr и завершается с кодом 1.

Пример с прогревом и выводом в JSON (прогресс уходит в stderr, поэтому
stdout остаётся чистым JSON):

```bash
python3 netspeed.py https://proof.ovh.net/files/10Mb.dat --warmup 1 --json > result.json
```

## Единицы измерения

| Величина | Единица | Как считается |
|---|---|---|
| Время запроса (среднее, медиана, мин., макс.) | миллисекунды (ms) | от отправки запроса до последнего байта тела ответа |
| Задержка (latency) | миллисекунды (ms) | от отправки запроса до получения заголовков ответа, среднее по запросам |
| Общий объём | мегабайты (MB, 1 MB = 1 000 000 байт) | сумма байт тела всех ответов |
| Скорость | мегабиты в секунду (Mbit/s, 1 Mbit = 1 000 000 бит) | общий объём в битах / суммарное время всех запросов |
| Скорость без задержки | мегабиты в секунду (Mbit/s) | общий объём в битах / суммарное время передачи тела (время запроса минус задержка) |

Мегабиты в секунду выбраны потому, что в них провайдеры и сервисы вроде
Speedtest указывают скорость интернета, так что результат легко сравнить.

Время запроса включает DNS, установку соединения и ожидание ответа сервера.
На маленьких файлах эти накладные расходы заметно занижают скорость, поэтому
скрипт отдельно показывает скорость без задержки. Прогревочный запрос
(`--warmup 1`) убирает из статистики эффект первого обращения, например
холодный DNS-кэш.

## Тесты

Тесты поднимают локальный HTTP-сервер на свободном порту, интернет не нужен.
Они также запускаются в GitHub Actions при каждом push.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m unittest -v
```
